# AERROSTRIKE X — プレイヤー・ジャーニーマップ分析と最適化

対象：アップロードされた `AERROSTRIKE-X.zip`（AFTERBURN 版、game.js 約 32KB）
目的：「戦闘機の魅力を感じ、夢中になれる」ゲームにするため、プレイヤーの体験をステージごとに分解し、離脱ポイントと感情の山・谷を特定して改修する。

---

## 0. 改修前の把握（コード理解）

| 領域 | 改修前の実装 | 評価 |
|---|---|---|
| 入力 | ドラッグ相対移動・WASD、アイコン行のタップ/ドラッグ判定、overlap 時の透過 | **優秀**。そのまま継承 |
| ループ | 120Hz 固定ステップ、28 秒でボス、撃破で 3 択強化 | 骨格は良い。単調化が早い |
| 敵 | 3 種（直進・蛇行・3way）、ランダム湧き | パターンが読めてしまい 2 分で飽和 |
| ボス | 1 種（SENTINEL）を HP だけ上げて繰り返し | セクター 2 以降の驚きがゼロ |
| ビジュアル | グリッド＋星＋レーダー円、3px 四角のパーティクル | 「空を飛んでいる」感覚が無い。撃破の手応えが弱い |
| 音 | 8 音の三角波ループ、単発トーン SFX | 曲がない。爆発が「ピッ」 |
| 成長 | 3 択（連射・威力・装甲）固定 | 選択の楽しさが薄い |
| 定着 | 難易度別ベスト、前回比、死因ヒント | 良い。ただし「次に解放されるもの」が無い |

## 2. 戦闘機の魅力を伝えるための演出設計

| 要素 | 実装 |
|---|---|
| **高度感** | 全機体の**地面への影**（空域ごとに濃さ調整）、低層雲（機体の下）と高層雲（機体の上を高速で通過）の 2 層パララックス |
| **速度感** | 地形 70px/s・低層雲 165px/s・高層雲 380px/s の多重スクロール、OVERDRIVE 時は全体 1.9 倍＋スピードライン |
| **機体の存在感** | 3 機体それぞれ独自のシルエット（可変後退翼／前進翼＋カナード／四発重攻撃機）、エンジン数ぶんの噴射炎とショックダイヤモンド、加算合成のグロー、主翼端の赤緑航法灯、バンク角で機体が傾き翼が縮む、飛行機雲 |
| **射撃の手応え** | 武器ごとのマズルフラッシュ色、加算合成の光弾、追尾弾の白煙、レーザーの白芯 |
| **編隊飛行** | ウイングマン（僚機）が左右後方に遅れて追従、タイトルでも 3 機編隊 |
| **撃墜の快感** | 閃光→火球→黒煙→破片→火花→衝撃波の 6 層爆発、大型機はヒットストップ、ボスはスロー＋連鎖爆発 |

## 3. サウンド設計（すべて Web Audio で合成、外部ファイルなし）

- **ミキサー**：マスター → コンプレッサー、BGM バス／SFX バスを分離、生成インパルスによる**ホールリバーブ**、アルペジオ用**エコー**
- **BGM シーケンサー**（先読みスケジューラ）
  - MENU：Am7–Fmaj7–Cmaj7–Em7、92BPM、パッド＋柔らかいアルペジオ＋メロディ
  - STAGE：Am–F–C–G、138BPM、キック／スネア／ハット、オクターブベース、16 分アルペジオ、4 小節後からリードメロディ（周回でオクターブ上へ）。OVERDRIVE 中はハイハット倍増
  - BOSS：Dm–B♭–C–A、152BPM、16 分ベース、ブラス風スタブ、緊迫したメロディ
- **ジェットエンジン**：三角波＋ローパスノイズのロア。推力・OVERDRIVE に追従
- **SFX 29 種**：武器 4 種、被弾、撃破（ノイズ＋サブベース）、大型爆発、砲台破壊、ボス撃破（多段爆発）、墜落、NOVA、P アイテム、エクステンド、WARNING サイレン、ビーム予告とビーム、雷鳴、低ライフ警告、クリア／ベスト更新／ゲームオーバーのジングル ほか
- **間引き**：同種 SFX の最短間隔を設定し、大量撃破時の音割れを防止
- **ハプティクス**（対応端末のみ）：被弾、爆弾、ボス撃破で振動

## 4. 継承した優れた設計（壊さないことを優先）

- ドラッグ相対移動・アイコンのタップ/ドラッグ判定・機体がアイコンに重なると透過
- Safari の可視領域追従（visualViewport）、セーフエリア対応
- 一時停止・タブ非表示で自動ポーズ、再開時 1.5 秒シールド
- 難易度別の記録、死因と次の一手のヒント、ダメージなしの操作練習
- `prefers-reduced-motion`：画面揺れ・フラッシュ・スピードラインを抑制

## 5. 検証

- `node tests/game-state.cjs`：改修前の全テストを新仕様に移植＋新機能（武器レベル、編隊ボーナス、エクステンド、補給機、3 ボス、ビーム命中、砲台破壊、機体解放、5 空域の描画、楽曲データ）を追加。全 7 グループ PASS
- Chromium 実機描画：デスクトップ／iPhone 縦／横、全 5 空域・3 ボス、墜落→リザルト、練習モードをスクリーンショットで確認。コンソールエラー 0
- オーディオ：Chromium で AnalyserNode により MENU/STAGE/BOSS 各トラックと全 SFX の出力を確認
- バランス：自動回避ボットで機体別・難易度別に 10 分シミュレーション。GOLIATH 一強・VALKYRIE 脆弱を検出して調整、初ボス第 2 形態の被弾集中を検出して緩和

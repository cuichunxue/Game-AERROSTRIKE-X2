Preserves the original arcade shooting concept, four weapon types, bombs, pickups, and local high score. Rebuilds the timing, collision, input, rendering and UI layers; adds synthesized audio, bosses, combo scoring, graze energy and per-sector upgrades. No third-party art, music or runtime dependencies.

Run by serving dist as a static website. Score and mute settings are stored only in the current browser. Audio starts after a user gesture. Sites edition is separate from the original GitHub Pages deployment.

AFTERBURN overhaul (2026-10): split source into src/js modules with a build step; adds three airframes, five sector environments, a wave director with formations, three boss types, weapon levels, a randomized upgrade pool, a synthesized music sequencer and layered SFX, and a layered explosion/particle system.

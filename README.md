# AERROSTRIKE X — AFTERBURN

指先で切り抜けるアーケード空戦シューティング。3 機の戦闘機、4 つの武器、5 つの空域、3 体のボス。画像・音声ファイルを一切使わず、グラフィックも音楽もすべてブラウザ内で生成します。

## 遊び方

`index.html` をブラウザで開くだけで遊べます（外部ファイル不要の 1 ファイル版）。
ダウンロード版は `AERROSTRIKE-X.zip` の `AERROSTRIKE-X.html` です。

| 操作 | タッチ | PC |
|---|---|---|
| 移動 | 空いた場所をドラッグ | WASD / 矢印キー |
| 攻撃 | 自動 | 自動 |
| 武器切替 | 下のアイコンをタップ | X |
| 爆弾（敵弾を一掃） | 右下の爆弾 | SPACE |
| 火力 2 倍（OVERDRIVE） | 右下の稲妻（100% で使用可） | C |
| 一時停止 | 右上 Ⅱ | P / ESC |
| 出撃・再挑戦 / 強化選択 | ボタン | ENTER / R ・ 1〜3 |

- **P アイテム**で武器レベルが最大 4 まで上がります（被弾すると 1 段階ダウン）。緑の**補給機**を撃つと P を落とします。
- 編隊を**全滅**させるとボーナス。敵弾を**かすめる**と必殺技が溜まります。
- ボスの**砲台**を壊すと本体に大ダメージ。PHANTOM の赤い予告線が出たらその列から離れてください。
- 5 万点ごとに**エクステンド**。セクター 3 到達で VALKYRIE、1 回で 25,000 点到達で GOLIATH が格納庫に配備されます。

## 開発

```
src/
  index.html, style.css
  js/00-core.js    共通処理・保存データ・機体・空域・ボス定義
  js/10-audio.js   合成音源（BGM シーケンサー、SFX、エンジン音）
  js/20-assets.js  発光スプライト・雲・戦闘機/敵/ボスのベクター描画
  js/30-world.js   空域の地形スクロール、雲、天候、パーティクル/爆発
  js/40-game.js    ゲームルール（ウェーブ、敵、ボス、武器、スコア）
  js/50-ui.js      画面・HUD・入力・メインループ・描画
tests/game-state.cjs  ルールの自動テスト
tools/build.cjs       1 ファイル版 index.html と zip を生成
docs/JOURNEY_MAP.md   プレイヤー・ジャーニーマップ分析
```

- 開発中は `src/index.html` を直接開けば分割ソースのまま動きます。
- ビルド：`node tools/build.cjs`（`--no-zip` で zip 更新を省略）
- テスト：`node tests/game-state.cjs`

記録はブラウザ内（localStorage）にのみ保存されます。音は最初のタップ／キー入力後に始まります。

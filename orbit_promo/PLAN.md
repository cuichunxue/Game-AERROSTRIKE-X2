# Orbit プロモーション動画 — 企画書

- 尺：78秒 ／ 1920×1080 ／ 30fps ／ H.264 + AAC（-14 LUFS、配信向け音量）
- 素材：実際のツール画面（ローカルで動かして撮影）＋モーショングラフィックス＋オリジナルBGM（numpy で作曲から合成まで自作したので、著作権の問題はありません）

## 1. 想定する視聴者のエンパシーマップ

**ペルソナ**：企画・マーケ・研究・品質管理などの職種で、Excelは毎日使うがプログラミングはしない人。明日の会議に向けて、夜遅くまでグラフを作っている。

| 象限 | 中身 | 動画での使いどころ |
|---|---|---|
| **言うこと（Say）** | 「グラフ作るだけで半日終わった」「もっと伝わる資料にしたい」 | S2のモノローグ |
| **考えること（Think）** | 「統計はわからないけど説得力は欲しい」「Pythonを覚える時間はない」「社外のサービスにデータを上げるのは怖い」 | S2のモノローグ、S6「RもPythonもいらない」、S8「データは外に出ない」 |
| **すること（Do）** | Excelの書式をいじり続ける、コピペ、スクショ、深夜残業 | S1の時計 23:47、S2のExcel風の野暮ったいグラフ |
| **感じること（Feel）** | 焦り、孤独、自信のなさ | 暗い画面、時計の秒針の音、心音 |
| **悩み（Pain）** | 時間がかかる／統計が難しい／社用PCにソフトを入れられない／情報漏えいが怖い | 4つのモノローグに1対1で対応させ、S5〜S8でひとつずつ解消 |
| **得たいもの（Gain）** | 一瞬で美しいグラフ、統計的に正しい根拠、会議で「おっ」と言われること | S9（翌朝の会議室）の感情のピーク |

## 2. 感情曲線の設計

共感（S1–S3）→ 静寂と落差（19.5秒で無音）→ サプライズ（20秒で最初の音の爆発・ロゴ登場）→ 爽快感（S5–S8：痛みを順番に解消）→ 感動（S9：前夜23:47と対になる翌朝9:00の伏線回収と、上司のひと言）→ 行動（S10：URL）

## 3. 絵コンテ（BPM 120、2秒＝1小節にカットを合わせています）

| 時間 | シーン | 映像 | 音 |
|---|---|---|---|
| 0–8 | フック | 時計 23:47、「明日の会議まで、あと9時間。」 | 秒針、暗いパッド、心音 |
| 8–16 | 悩み | 4つのモノローグ（グリッチ演出）、数字の表、Excel風のグラフ | 刻むベース、フィルターが徐々に開く、グリッチ音 |
| 16–20 | 溜め | 数字が中央に吸い込まれ「足りなかったのは——」、0.5秒の完全な無音 | ライザー、スネアロール、無音 |
| 20–28 | 解放 | 粒子が爆発して軌道を描き、Orbitのロゴが登場。「貼り付けた瞬間、データが軌道に乗る。」 | インパクト音、フルビート |
| 28–36 | デモ1 | 実画面：Ctrl+V → クリック → バブルチャート | ウーッシュ、アルペジオ、主旋律 |
| 36–44 | デモ2 | 回帰線・95%信頼区間・予測区間・4象限への注釈、`statsmodels` のコードに取り消し線 | — |
| 44–52 | デモ3 | 7種類のチャートを3Dカルーセルで見せてからグリッドに整列 | — |
| 52–60 | 価値 | インストール不要／データは外に出ない／PNG・SVG・CSV／無料・登録不要 | 1小節ごとにピン音 |
| 60–68 | 感動 | 翌朝 9:00 → 会議室のスクリーン →「このグラフ、すごく分かりやすいね。」→「データが、あなたの言葉になる。」 | ドラムを抜いてエレピとパッドだけに |
| 68–78 | 行動喚起 | ロゴ、「あなたのデータは、もっと語れる。」、URL、「今すぐ、ブラウザで。」 | フルビート → 最後の和音をDメジャーにして明るく終える |

## 4. 表現の事実確認

ソースコード（index.html）で次の点を確認したうえで表現しています。

- グラフは棒・円・散布図/バブル・箱ひげ図・ツリーマップ・ヒストグラム・パレート図の7種類。
- 回帰（線形・2次・3次）、信頼区間・予測区間（90/95/99%）、平均クロスラインによる4象限に対応。
- `fetch` や XHR などの通信処理はありません。データはブラウザの外に送信されません。
- PNG・SVG・CSVで書き出せます。静的ページなので無料・登録不要・インストール不要です。

## 5. 再生成の手順（source/）

1. `bgm.py` で bgm.wav を生成します（`python3 bgm.py bgm.wav`）。
2. `shoot2.mjs` で実画面を撮影します（Playwright を使用）。
3. `film.html` に `render(t)` という時刻を受け取って描画する関数があり、`render.mjs` で各フレームを書き出します。
4. 最後に ffmpeg でフレームとBGMを合成します。
